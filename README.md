# Computer Science — Data Structures Practicals

Python 3 programs separated from the original practicals text file.

## Practicals

1. Library borrowing statistics
2. Linear and binary search
3. Salary sorting (selection sort and bubble sort)
4. Stack: undo and redo
5. Queue: event processing
6. Linked list: student records
7. Hash table with chaining
8. Hash table with linear probing
9. Graph traversal: BFS and DFS
10. Binary search tree

## Run

Install Python 3, open a terminal in this folder, and run an individual practical:

```bash
python 01_library_statistics.py
```

Replace the filename with the practical you want to run.
